# v0.1.3 实验版

Gemini Windows 指定构建的非官方简体中文界面补丁，与 Google 无从属或背书关系。它修改本机客户端资源，提供兼容性检查、备份和校验恢复；不修改 Google 账号语言、套餐或地区。

## 适用范围

- 仅适配已登记文件指纹的 Gemini Windows 1.16.0 x64 构建；相同版本号不保证相同构建。
- 需要已有 Node.js 20+；本机验证环境为 Windows 11 x64、Node.js 24.18.0。
- 无第三方 npm 依赖，无需 `npm install`。下载并解压源码，按 README 先诊断；安装或恢复前完全退出 Gemini。
- 不含 Google EXE、ASAR、账号资料或客户端备份。

## 本次修复

- 收窄主页和设置页翻译范围，减少同名聊天内容、列表记录和代码被误翻译的风险。
- 区分备份存在与备份有效，完善损坏备份、重复安装和恢复检查。
- 修复特殊美元符号替换，改善运行时诊断文件写入与版本一致性。
- 增加内容保护、拆分文字、图标和备份异常回归检查。

## 已知限制与恢复

仍有部分二级设置、Gems 旧版管理页、推荐模板和动态提示未覆盖。品牌、模型名及用户内容有意保留原文。67 项合成页面检查不代表全部界面已汉化。

客户端或网页更新后补丁可能失效。请先诊断，不将旧资源覆盖到新版客户端。恢复依赖有效备份及受支持构建，不承诺所有异常状态都能自动恢复。内容误译或安装问题请先阅读项目的 `docs/RECOVERY.md`；具体证据见 `docs/VALIDATION.md` 与 `docs/REVIEW_FIXES.md`。
